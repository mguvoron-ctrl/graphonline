Запуск GraphOnline на Mac

1. Установите [Docker Desktop для Mac](https://www.docker.com/products/docker-desktop/). Выберите версию для своего процессора: Apple Silicon или Intel. Откройте Docker Desktop и дождитесь запуска.
2. Распакуйте `graphonline-macos.zip` в обычную папку, например `Документы/graphonline-macos`.
3. Откройте `Start GraphOnline.command`. Файл запустит приложение и откроет браузер. Обычно адрес — `http://localhost:8080`; если этот порт занят при первом запуске, будет выбран свободный порт до 8090.

PHP, Node.js, Homebrew и Xcode для обычного просмотра не нужны: готовая сборка включена в архив. Интернет нужен для первого скачивания официального образа PHP. Основной сценарий работает на Intel и Apple Silicon без принудительной эмуляции архитектуры.

Если macOS не разрешает открыть скачанный `.command` двойным кликом, откройте Терминал в распакованной папке и выполните:

```sh
bash tools/local.sh start
```

Чтобы открыть Терминал в папке, можно перетащить её в окно Терминала после ввода `cd `, затем нажать Enter. Не нужно отключать защиту macOS.

Для остановки откройте `Stop GraphOnline.command` или выполните:

```sh
bash tools/local.sh stop
```

Повторный запуск использует тот же экземпляр и порт. Закрытие вкладки браузера не останавливает сервер. Локальные черновики находятся в браузере; опубликованные графы — в `tmp/saved` внутри распакованной папки. Остановка сохраняет данные. Если перенести папку или изменить порт, браузер увидит другой адрес хранилища; нужные графы сначала экспортируйте в файл.

Если порт сохранённого экземпляра занят другой программой, запустите с явно выбранным портом:

```sh
GRAPHONLINE_PORT=8090 bash tools/local.sh start
```

Логи для диагностики:

```sh
bash tools/local.sh logs
```

Архив содержит изменённую версию из текущей рабочей копии. Обычный `git clone` исходного репозитория не загрузит эти изменения, пока они не опубликованы в Git.

Скрипт синтаксически совместим с Bash 3.2; запуск через Compose проверен в Linux, а наличие обеих архитектур проверено в индексе образа. На физическом Mac эта сборка пока не проверялась.
