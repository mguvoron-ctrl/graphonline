# Масштаб, кадры и автосохранение

## Ошибка масштаба

Старый обработчик читал `wheelDelta`/`detail` и игнорировал стандартное `WheelEvent.deltaY`. Событие приближения без устаревшего поля уменьшало масштаб со 100% до 77%; действие браузера при этом не блокировалось. Теперь нормализуются пиксельные, строчные и страничные дельты, приближение привязано к указателю, а обработчик зарегистрирован с `passive: false`. Для Safari добавлены `gesturestart/change/end`; пересекающиеся wheel-события не применяются второй раз. Масштаб ограничен диапазоном 1–2000%, нечисловые значения отвергаются.

Размер Canvas в CSS-пикселях хранится отдельно от размера буфера. Обе величины обновляются при изменении DPR, включая переход Retina → 1x. Повторный resize с теми же размерами не пересоздаёт буфер. Каждый кадр начинает рисование с известного преобразования, а координаты указателя учитывают фактический CSS-размер элемента. Подгонка графа использует размер экрана независимо от предыдущего приближения. Завершение фоновой раскладки сохраняет масштаб и положение камеры, которые пользователь выбрал во время расчёта.

## Разделение действий

Использованы TypeScript, браузерный `requestAnimationFrame`, существующий IndexedDB и Playwright; дополнительные зависимости не понадобились.

- `redrawGraph()` сохраняет консервативный контракт старых расширений: документ мог измениться, поэтому нужны автосохранение и проверка типа графа.
- `redrawGraph(false)` обозначает только изменение вида. Это используется при масштабе, панорамировании, resize, выделении и показе шагов обхода.
- `MarkDocumentChanged(false)` отмечает изменение геометрии без повторного поиска отрицательных/параллельных рёбер. Перетаскивание отмечает каждый фактический сдвиг, даже после первого снимка Undo.
- `FrameScheduler` объединяет запросы в один кадр. `flushRender()` синхронно выполняет ожидающий кадр перед скачиванием PNG рабочего поля. Полный граф и SVG по-прежнему рисуются отдельно из текущей модели.
- Неизменившееся сообщение не пересоздаётся при движении мыши: элементы управления сохраняют фокус. Начало новой анимации пути останавливает предыдущий таймер.

Это этап выделения модели, а не централизованная система команд для всех плагинов. Любые неизвестные перерисовки остаются консервативными. Сам кадр ещё рисует весь граф; постоянный кэш геометрии и пространственный поиск требуют надёжной инвалидации.

## Сохранение

`Autosave` отслеживает версию изменения и сохраняет пару `{xml, reference}`. Снимок создаётся после 400 мс покоя; чистый документ не сериализуется из-за действий с камерой. Завершившаяся запись старой версии не помечает более новое изменение как сохранённое. Параллельные запросы flush ожидают текущую запись, затем проверяют свежую версию. Ошибка записи оставляет документ грязным для следующей попытки. Изменение одной ссылки тоже сохраняется.

Старые расширения иногда меняют объекты напрямую без перерисовки. Для них остаётся принудительная проверка XML раз в 10 секунд. Дополнительный flush вызывается при скрытии страницы. Асинхронная запись при закрытии браузера не гарантирована; для переноса важных графов нужен экспорт в файл. Ограничение одного общего черновика между вкладками остаётся отдельной задачей.

## Измерение и проверки

```sh
npm run benchmark:ui
# При системном Chromium или другом сервере:
CHROMIUM_PATH=/usr/bin/chromium PLAYWRIGHT_BASE_URL=http://127.0.0.1:8080 npm run benchmark:ui
```

Замер 2026-11-04, Chromium/Linux, DPR 2, 50 вершин и 49 рёбер. Серия из 100 запросов масштаба выполняется в одном JS-цикле; это не 100 отдельных кадров. Ожидание после серии включает отложенный кадр и debounce сохранения. Периодическая совместимая проверка выключена только на время замера.

| Работа за серию | До | После |
| --- | ---: | ---: |
| Рисование Canvas | 100 | 1 |
| Проверки типа графа | 100 | 0 |
| Сериализация XML | 1 | 0 |

Время самого цикла запросов: 157,3 → 0,4 мс; после изменения отрисовка выполняется отложенно, поэтому это не сравнение полной задержки кадра. Последующее прямое изменение старого графа с обычным `redrawGraph()` в обеих версиях дало одну запись корректного черновика.

Модульные проверки покрывают объединение кадров, синхронный flush, версии сохранения, конкурирующие записи и повторную попытку после ошибки. Браузерные проверки покрывают направление масштаба и неподвижную точку под указателем при DPR 1/2/3, смену DPR, реальное перетаскивание, текущий PNG, остановку таймера, сохранение камеры после раскладки и совместимый аудит. Safari GestureEvent проверен синтетическими событиями в Chromium; физический Mac и реальный Safari пока не проверены.

## Постоянный широкий редактор

Редактор сразу занимает всю ширину и доступную высоту вкладки. `tpl/home.php` задаёт признак `editorLayout`, а основной шаблон выводит класс `graphonline-editor` ещё на сервере. Стили входят в основной CSS, загружаемый в `<head>`: широкий вид появляется до выполнения JavaScript. Узкая компоновка и переключение в неё удалены. Формы создания матриц и остальные страницы этот признак не получают.

Кнопка полного экрана удалена вместе с контроллером Fullscreen API и его обработчиками. Широкая компоновка постоянна; навигация, инструменты, алгоритмы и диалоги доступны сразу. Если нужно скрыть панели самого браузера, используется его собственный полноэкранный режим — на Mac обычно Control + Command + F. Веб-страница не запрашивает этот режим автоматически.

Для ранее закэшированного JavaScript шаблон сохраняет скрытые неинтерактивные элементы со старыми ID: старый код обращается к ним при инициализации. Это не кнопка; элементы исключены из взаимодействия и дерева доступности. Основной JS больше не содержит контроллер полноэкранного режима.

## Сворачивание верхних панелей

Кнопка «Панели» скрывает навигацию, инструменты и сообщение с управлением алгоритмом. Над Canvas остаются поиск вершины и кнопка «Инструменты». Они находятся в отдельной строке обычного потока документа и не перекрывают Canvas или сообщения. На узких экранах строка перестраивается, а надпись кнопки заменяется значком с локализованными `aria-label` и подсказкой.

Сворачивание использует CSS-класс и не пересоздаёт элементы управления, поэтому выбранные параметры и текущий алгоритм сохраняются. Esc сохраняет широкий вид и не разворачивает скрытые панели автоматически. Кнопка сообщает состояние через `aria-expanded` и перечисляет управляемые панели в `aria-controls`. Это изменение вида не меняет документ и не запускает его сериализацию.

Размер Canvas пересчитывается по свободной части окна. ResizeObserver учитывает изменения сообщения и всей секции Canvas, в том числе появление статуса сохранения и прогресса раскладки. Масштаб и положение камеры сохраняются. На контрольном окне 1440 × 1000 с шагами BFS сворачивание увеличило высоту поля с 814 до 992 пикселей; на других размерах выигрыш зависит от высоты панелей. При недостатке высоты остаётся прокрутка, чтобы инструменты были доступны.

Верхняя панель имеет единую высоту кнопок и компактные отступы. На ширине до 1000 пикселей кнопки показывают значки, а все функции, включая настройки, остаются доступны. Сервис-воркер загружает новый комплект CSS и JavaScript без HTTP-кэша; при смене версии страница один раз автоматически перезагружается, чтобы не смешивать файлы разных сборок.
